# Data Cleaning & Preparation

This project focuses on cleaning and preparing a dataset for further analysis using Jupyter Notebook and Python.

## Tools Used

* Python
* Jupyter Notebook
* Pandas
* NumPy

## Tasks Performed

* Loaded and explored the dataset
* Identified missing values
* Handled duplicate records
* Checked and corrected data types
* Cleaned inconsistent data
* Prepared the dataset for analysis

## Files

* `Data_Cleaning_and_Preparation.ipynb` – Jupyter Notebook containing the complete data cleaning process.

## Outcome

The dataset was cleaned and structured into a suitable format for further analysis and visualization.
