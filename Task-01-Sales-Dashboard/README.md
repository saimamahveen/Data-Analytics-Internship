# Task 01 – Sales & Profit Dashboard

## 📊 Overview

Created an interactive Sales & Profit Dashboard using Microsoft Excel to analyze business performance and present key insights through data visualization.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization

The dashboard provides a visual analysis of sales and profit performance across different categories, regions, and other business dimensions.

To transform raw sales data into a clear and interactive dashboard that helps identify sales trends, profit performance, and key business insights.

## 💡 Skills Demonstrated

- Pivot table analysis
- Dashboard creation
- Data visualization
- Business insights generation
