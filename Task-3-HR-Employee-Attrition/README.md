# HR Employee Attrition Report

An interactive HR analytics report created using Microsoft Power BI to analyze employee attrition and identify patterns affecting employee turnover.

## Tools Used

* Microsoft Power BI
* Data Cleaning & Transformation
* Data Visualization
* DAX

## Analysis Performed

* Analyzed overall employee attrition
* Examined attrition by department
* Analyzed attrition based on age and gender
* Studied job roles and employee turnover
* Analyzed factors related to employee attrition
* Created interactive charts and KPI visualizations

## Key Skills Demonstrated

* Data cleaning and transformation
* Dashboard development
* Data visualization
* KPI analysis
* Business-oriented data analysis

## Report Preview

The Power BI report provides an interactive view of employee attrition and helps identify important HR trends and patterns.
