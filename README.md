# Task 01 – Sales Dashboard

## 📊 Overview

Created an interactive Sales Dashboard using Microsoft Excel to analyze sales performance and identify key business insights.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Visualization

## 📈 Dashboard Features

- Total Sales
- Sales by Category
- Sales by Region
- Sales Trends
- Top/Low Performing Products
- Interactive visualizations

## 🎯 Objective

To transform raw sales data into an interactive dashboard that helps understand sales performance and identify important trends and patterns.

## 📌 Key Skills

Excel | Data Analysis | Data Visualization | Dashboard Development
